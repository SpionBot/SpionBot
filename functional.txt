  Проект: Telegram-бот "Шпион" (игра в стиле Spy) с тематическими картами из Dota 2 / Clash Royale / Brawl Stars.

  Кратко
  - Бот управляет игровыми комнатами, раздаёт роли/карты, ведёт голосование и поддерживает одиночный режим.
  - Есть экономика (баланс звёзд, подсказки, донаты) и админ-панель.
  - Хранилища: PostgreSQL для игровых сущностей, Redis для кэша/подсказок и вероятностей.
  - Инфраструктура: Docker Compose + PostgreSQL + Redis + ELK (Elasticsearch/Kibana/Filebeat).

  Технологический стек
  - Python 3.12, asyncio
  - python-telegram-bot 20.7 (async)
  - asyncpg (PostgreSQL)
  - redis (Redis)
  - httpx/aiohttp/requests (HTTP)
  - Pillow (+ pillow-avif-plugin) для обработки изображений
  - Docker/Docker Compose

  Сервисы и инфраструктура
  - PostgreSQL: хранит комнаты, игроков, аккаунты, отчёты, кэш изображений.
  - Redis: кэш подсказок и вероятности выбора шпионов в комнате.
  - ELK: Elasticsearch + Kibana + Filebeat для логирования контейнеров.

  Основные модули
  - main.py: старт приложения, регистрация хендлеров, запуск фоновых задач.
  - handlers/commands.py: весь игровой и бизнес-логика (команды, платежи, админка, поддержка).
  - handlers/callback.py: обработчики inline-кнопок (подсказки, публичные комнаты, смена шпионов и т.д.).
  - handlers/button.py: клавиатуры и текстовые шаблоны.
  - database/init.py: создание и миграция схемы БД.
  - database/actions.py: слой запросов к БД.
  - database/redis.py: операции с Redis (подсказки, вероятности, комнаты).
  - utils/*: декораторы (rate limit, блокировки), фоновые задачи, обработка изображений.
  - const.py: константы режимов/цен/ID админов/наборы карт.

  Данные (PostgreSQL)
  - rooms: комнаты (режим, приватность, слово, шпионы, spectators, старт игры, срок жизни).
  - players: участники (роль, слово, ссылка на карту).
  - user_accounts: баланс звёзд, подсказки, статистика игр.
  - referrals: рефералы.
  - image_cache: file_id изображений Telegram для повторного использования.
  - user_reports: обращения в поддержку с текстом/файлом.

  Данные (Redis)
  - Подсказки по героям/картам (по уровню сложности).
  - Вероятности выбора шпиона в комнате (с TTL).

  Игровой функционал (мультиплеер)
  - Создание комнаты /create.
  - Вход по ID /join <id> и список публичных комнат с пагинацией.
  - Приватные/публичные комнаты: /public, /private.
  - Выбор режима: Clash Royale, Dota 2, Brawl Stars.
  - Старт игры /startgame:
    - выбирается слово/карта из выбранной темы;
    - назначаются шпионы (1..N в зависимости от игроков);
    - каждому игроку отправляется карта или карточка шпиона;
    - ведётся учёт ролей и статистики.
  - Изменение числа шпионов до старта: /spies <n> и inline-кнопки.
  - Перезапуск игры /restart.
  - Просмотр роли/слова /word.
  - Список игроков и ролей (для админа комнаты) /players.
  - Статус комнаты /room.
  - Комнатный чат и пересылка голосовых (нельзя зрителям).

  Голосование и spectators
  - Во время игры создатель может запустить голосование ("🗳️ Голосование").
  - Голосование анонимное, время ограничено.
  - Победитель голосования переводится в spectators.
  - Логика победы:
    - мирные побеждают, если все шпионы изгнаны;
    - шпионы побеждают, если превышен лимит ошибочных изгнаний мирных.
  - После завершения — автоматический рестарт комнаты.

  Одиночный режим
  - /single: игра на одном устройстве, пошаговое раскрытие карты.
  - Выбор количества игроков и количества шпионов.
  - Навигация "следующий/предыдущий", скрытие/открытие карты.
  - Сессии хранятся в памяти, периодически очищаются фоновой задачей.

  Подсказки и экономика
  - Подсказки трёх уровней: easy/medium/hard.
  - Стоимость задаётся в const.py.
  - Подсказки покупаются за звёзды (Telegram Stars, XTR).
  - Личный кабинет: баланс, количество подсказок, статистика игр.
  - Донат /donate и пополнение баланса (инвойсы XTR).
  - Реферальная система: генерируется реф. код/ссылка, ведётся счётчик приглашённых.

  Подсказки по персонажам
  - Фоновая задача регулярно запрашивает подсказки с внешнего API (URL/HASH из .env).
  - Подсказки кэшируются в Redis и выдаются по уровню сложности.

  Поддержка и жалобы
  - "Поддержка" в меню: пользователь отправляет текст и/или фото.
  - Фото сжимается перед сохранением.
  - Обращения сохраняются в БД и доступны админам.

  Админ-функции
  - Админ панель (по списку ADMIN в const.py).
  - Просмотр статистики бота и сингл-мода.
  - Массовая рассылка сообщений.
  - Модерация жалоб и ответы пользователям.

  Фоновые задачи
  - cleanup: удаление старых комнат и кэша изображений.
  - generate_clue: регулярное обновление подсказок.
  - update_connect: периодический keep-alive запрос.
  - cleanup_single_mode: очистка одиночных сессий.

  Конфигурация
  - .env: API_TOKEN, DATABASE_URL, REDIS_HOST/PORT, URL/HASH для подсказок, и т.д.
  - Dockerfile и docker-compose.yaml для локального/серверного развёртывания.
